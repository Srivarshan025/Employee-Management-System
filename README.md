# Employee Management System

A console-based Employee Management System built using Java, JDBC, and MySQL.

## Features

* Add Employee
* View Employees
* Search Employee by ID
* Update Employee
* Delete Employee

## Technologies Used

* Java
* JDBC
* MySQL
* Maven

## Database

MySQL database named `employee_db` with table `employees`.

## CRUD Operations

* Create
* Read
* Update
* Delete
